Projeto interno do grupo Cangaço no Espaço, utilizando como base o projeto do foguete Mercúrio desenvolvido também pelo grupo.

Passamos a adotar modelo com corpo em tubo de papel, possuindo densidade 0,68g/cm³;
Diâmetro externo de 44mm;
Diâmetro interno de 40mm;
Motor Bombona construído pela equipe;
O sistema de eletrônica desenvolvido pela e para OBA (Olimpiada Brasilira de Aeromodelismo).
